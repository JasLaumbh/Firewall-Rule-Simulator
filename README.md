# 🚀 Firewall Rule Simulator

A Python-based simulation of a firewall using **iptables**-like functionality to filter network packets by ports, protocols, and other criteria. This project is designed to showcase how Linux-based firewalls work in handling traffic through rules.

---

## 🎯 Features

- Simulates packets with various protocols, ports, and source IP addresses.
- Allows you to define firewall rules (allow or deny packets based on protocol and port).
- Simulates and prints the results of packets being checked against the firewall rules.
- Provides a simple demonstration of how a basic firewall works in practice.

---

## 🛠️ Tech Stack

- **Python**: Core programming language for the firewall simulation.
- **Random Module**: Used to simulate random network packets (protocol, port, and IP).
